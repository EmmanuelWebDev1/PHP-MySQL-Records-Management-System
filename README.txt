NEXORA SOLUTIONS WEBSITE
========================

Files
- index.html: page structure and content
- css/style.css: responsive styling and visual design
- js/script.js: mobile navigation, current year, and reveal effects

How to run
1. Extract the ZIP folder.
2. Open index.html in your browser.
3. For local development, open the folder in Visual Studio Code and use Live Server if installed.

Notes
- This is a front-end static website built with HTML, CSS, and vanilla JavaScript.
- The architectural hero illustration is created with CSS, so there are no extra image assets to manage.
- Google Fonts are loaded online; the page will fall back to system fonts if offline.
- Replace the example email address hello@nexorasolutions.example with your real contact email before publishing.
- The client names and performance figures are sample content; update them to match your real business.
